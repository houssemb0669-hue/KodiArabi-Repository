# KodiArabi Repository

المستودع الرسمي لإضافات KodiArabi.

## الأقسام

- 📺 Live TV — البث المباشر وIPTV
- 🎬 Movies — الأفلام
- 📺 Series — المسلسلات
- 🔤 Subtitles — الترجمة
- 🌐 Web — إضافات الويب

## ملف المستودع

الملف الرئيسي:

`addons.json`

يحتوي على قائمة الإضافات التي يستطيع KodiArabi تحميلها وتثبيتها.

## أنواع الإضافات

- `web` — إضافة ويب
- `m3u` — قائمة IPTV / M3U
- `direct` — رابط بث مباشر

هذا المستودع مخصص للمصادر القانونية والمفتوحة والمتاحة للاستخدام.
