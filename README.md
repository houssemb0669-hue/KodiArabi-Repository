# 🇩🇿 KodiArabi Repository

المستودع الرسمي لإضافات ومصادر **KodiArabi**.

## 📦 الأقسام

- 📺 Live TV — البث المباشر
- 🎬 Movies — الأفلام
- 📺 Series — المسلسلات
- 🔤 Subtitles — الترجمة
- 🌐 Web — إضافات الويب

## 🇩🇿 المصادر الحالية

يحتوي المستودع حاليًا على مصدر للقنوات الجزائرية العامة.

## 🔌 أنواع الإضافات

| النوع | الوصف |
|---|---|
| `m3u` | قوائم IPTV / M3U |
| `direct` | روابط البث المباشر |
| `web` | خدمات وصفحات الويب |

## 📄 ملف المستودع

يقرأ KodiArabi قائمة الإضافات من:

`addons.json`

## ⚖️ سياسة المحتوى

يتم قبول المصادر القانونية والمفتوحة والمتاحة للعامة فقط.

لا يهدف هذا المستودع إلى توفير المحتوى المقرصن أو تجاوز الاشتراكات أو الحماية.

## 🤝 المساهمة

راجع `CONTRIBUTING.md` لمعرفة طريقة إضافة مصدر جديد.
