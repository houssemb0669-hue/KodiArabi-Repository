# KodiArabi Repository

المستودع الرسمي لإضافات KodiArabi.

## ملف المستودع

الملف الرئيسي هو:

`addons.json`

ويحتوي على قائمة الإضافات التي يستطيع تطبيق KodiArabi تحميلها وتثبيتها.

## أنواع الإضافات

- `web` — إضافة ويب
- `m3u` — قائمة IPTV / M3U
- `direct` — رابط بث مباشر

هذا المستودع في مرحلته الأولى للاختبار والتطوير.
